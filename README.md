# git-kt2

Учебный репозиторий для контрольной точки №2 по дисциплине «Технологии программирования».

## Калькулятор

Модуль `calculator.py` содержит функции базовых арифметических операций:

- `add(a, b)` — сложение;
- `subtract(a, b)` — вычитание;
- `multiply(a, b)` — умножение;
- `divide(a, b)` — деление (при делении на ноль выбрасывается `ValueError`).

## Запуск

```
python calculator.py
```
